## 2. Last-Minute Technical Questions (With Answer Tips)

### Java/Python API
- **Q:** How do you secure REST APIs?  
  **A:** Use HTTPS, JWT tokens, input validation, role-based access.

- **Q:** What is Dependency Injection?  
  **A:** Technique for decoupling components, managed by frameworks (Spring, Flask extensions).

- **Q:** Difference between Monolithic and Microservices?  
  **A:** Monolith: Single deployable unit; Microservices: Modular, independent services.

### Frontend
- **Q:** How does Angular communicate with backend?  
  **A:** Using HttpClient for REST calls; RxJS for async handling.

### DevOps/Cloud
- **Q:** How do you deploy a Dockerized app?  
  **A:** Build Docker image → push to registry → run on server/cloud.

- **Q:** What is CI/CD?  
  **A:** Continuous Integration/Deployment: Automate build, test, deploy steps.

## 3. STAR Format for Behavioral Answers

- **Situation:** Brief context
- **Task:** What was needed
- **Action:** What you did
- **Result:** Outcome

**Example:**  
_"Faced production downtime (Situation); needed quick fix (Task); diagnosed logs, rolled back release (Action); restored service in 20 mins (Result).”_
