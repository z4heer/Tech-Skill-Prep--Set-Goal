## 🎯 Combined Goal: Learn **Blockchain + Golang** Together

---

## 🧭 Step-by-Step Learning Roadmap

### 🔹 Phase 1: Foundation (Week 1–2)

| Goal                           | Resources / Action                                                             |
| ------------------------------ | ------------------------------------------------------------------------------ |
| Learn Golang Basics            | [Tour of Go](https://tour.golang.org/), Learn Go with Examples (Go by Example) |
| Understand Blockchain Concepts | Read: *Mastering Blockchain*, Watch: *Simply Explained – Blockchain*           |
| Practice Go fundamentals       | Build: CLI tool, REST API using `net/http`, JSON serialization                 |

---

### 🔹 Phase 2: Blockchain with Go (Week 3–5)

| Task                              | Tools/Tech                                                                                                |
| --------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 🧱 Build a basic Blockchain in Go | Learn from: [Build Your Own Blockchain in Go](https://jeiwan.net/posts/building-blockchain-in-go-part-1/) |
| 📦 Learn Go Modules + Packages    | `go mod`, custom package organization                                                                     |
| 🔗 Implement proof-of-work logic  | Go + SHA256                                                                                               |
| 🧾 Add transactions and wallets   | Public/private key cryptography in Go                                                                     |

---

### 🔹 Phase 3: Real-World Blockchain Projects (Week 6–8)

| Goal                                 | Description / Tools                           |
| ------------------------------------ | --------------------------------------------- |
| Hyperledger Fabric (Chaincode in Go) | Learn smart contract dev using Go             |
| Cosmos SDK (App-specific blockchain) | Use Go to build your own PoS blockchain       |
| Tendermint Core                      | Explore consensus layer written in Go         |
| IPFS in Go                           | Learn decentralized storage using Go IPFS lib |
